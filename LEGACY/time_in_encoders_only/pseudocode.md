# \## DURING TRAINING#### Given:  training set { (u\_i on D, b\_i on ∂D) } for i=1..N  latent dim r  patch shapes:     E\_int ⊂ R^3       (interior patch in x,y,t)     E\_bdy ⊂ R^2       (boundary patch in boundary coordinates)     D\_dec ⊂ R^3       (decoder patch in x,y,t)  hyperparams α (reconstruction weight), ρ (SPD barrier), lr, epochs#### Initialize:  NN\_e\_int       interior encoder GF   ẽ\_int: R^(n\*NE\_int) -> R^r  NN\_e\_bdy       boundary encoder GF   ẽ\_bdy: R^(n\_bdy\*NE\_bdy + geom) -> R^r  NN\_dec         decoder GF            d̃: R^r -> R^(n\*ND\_dec)  A\_raw          unconstrained params for A (later mapped to SPD)#### Define SPD map:  A = SPD(A\_raw)   e.g. A = L L^T + εI, or symmetric + logdet barrier###### For epoch = 1..epochs:  total\_loss = 0######   For each minibatch B ⊂ {1..N}: (subset of data that is used for one gradient operation)    loss\_latent = 0    loss\_recon  = 0######     For each sample i in B: (subset of data in one minibatch)######      1) Sample M random 4D training patches Q\_k ⊂ D (in x,y,t). Each patch is a small 3D box around a centre p\_k      Choose centres p\_k ∈ D,  k=1..M      Define patches Q\_k = box(p\_k; hx, hy, ht)      For k = 1..M: (loop through each sample) ######       2) Build "true" latent at centre via interior encoder         u\_patch = extract(u\_i, neighbourhood = p\_k + E\_int)        ℓ\_true = NN\_e\_int( pool(u\_patch) )    pool = averages over E\_int subcells######       3) Build latent boundary data on ∂Qₖ (If I only knew the latent variables on the boundary of this small space–time patch, could an elliptic PDE reconstruct the latent variable at the centre?)        Inputs (for one training sample i and one patch Q\_k):        u\_i          : ground-truth interior field on D = Ω×\[0,T]   (training only)        b\_i          : observed boundary data on ∂D                 (train \& test)        Q\_k          : a 3D space–time patch (e.g. small box) with centre p\_k        {q\_j}        : discrete boundary grid points on ∂Q\_k, j=1..N\_b        E\_int        : interior encoder neighbourhood shape in R^3        E\_bdy        : boundary encoder neighbourhood shape in boundary coordinates        NN\_e\_int     : interior encoder network  (semi-local GF)        NN\_e\_bdy     : boundary encoder network  (semi-local GF)        pool\_int(.)  : pooling operator to turn local patch values into a vector        pool\_bdy(.)  : pooling operator for boundary neighbourhood        geom(.)      : function that returns local boundary geometry/orientation features        Output:        f\_k          : boundary condition function on ∂Q\_k (discrete or interpolated), representing ℓ|∂Q\_k######       3A) Evaluate discrete latent values on boundary points        Initialize array L\_bdy\[j] ∈ R^r for j = 1..N\_b        For each boundary point q\_j on ∂Q\_k:          Determine whether q\_j lies on the TRUE global boundary ∂D or not.          if is\_on\_global\_boundary(q\_j):            --- Use BOUNDARY encoder: ε∂(b) ---            1) Extract local neighbourhood of boundary observations around q\_j            b\_local = extract\_boundary\_neighbourhood(b\_i, centre=q\_j, shape=E\_bdy)            2) Extract geometry / orientation features at q\_j              Examples:                - spatial outward normal n(x,y) if (x,y)∈∂Ω                - a "time normal" ±e\_t if q\_j lies on t=0 or t=T surface                - tangential directions / side-id / signed distance to corners            g\_local = geom(q\_j)            3) Pool neighbourhood into finite vector (averages over bins etc.)            z\_bdy = pool\_bdy(b\_local, g\_local)            4) Encode to latent            L\_bdy\[j] = NN\_e\_bdy(z\_bdy)          else:            --- Use INTERIOR encoder: ε(u) ---            1) Extract local space–time neighbourhood of u around q\_j (training only)            u\_local = extract\_interior\_neighbourhood(u\_i, centre=q\_j, shape=E\_int)            2) Pool neighbourhood into finite vector            z\_int = pool\_int(u\_local)            3) Encode to latent            L\_bdy\[j] = NN\_e\_int(z\_int)######       3B) Convert discrete boundary latents into boundary condition f\_k - function/set of vectors containing the latent boundary points of the patch        Use L\_bdy\[j] directly as Dirichlet values at boundary nodes.        PDE solver will apply them at those nodes.        f\_k\_boundary\_nodes := { (q\_j, L\_bdy\[j]) } for j=1..N\_b######       STEP 4: Per-time-slice latent elliptic solve (time-invariant A)###### &nbsp;     	Inputs:&nbsp;     	Spatial patch P\_k ⊂ Ω&nbsp;     	Time indices {t\_1, ..., t\_Nt}&nbsp;     	Latent boundary functions f\_k^(n) : ∂P\_k → R^r   for n = 1..Nt&nbsp;     	Learned SPD matrix A\_xy ∈ R^(2r × 2r)&nbsp;	Outputs:&nbsp;   	PDE-predicted latent field ℓ\_pde(x, y, t\_n) on P\_k for each time slice&nbsp;   	Latent values ℓ\_pde(p\_xy, t\_n) at spatial patch centre p\_xy###### ###### &nbsp;     4A: Assemble spatial elliptic operator (once)###### &nbsp;	Discretise spatial patch P\_k with a 2D grid or FE mesh:&nbsp;   	Interior nodes {x\_m}      for m = 1..N\_int&nbsp;   	Boundary nodes {x\_b}      for b = 1..N\_bnd&nbsp;	Assemble block-sparse stiffness matrix K\_xy(A\_xy) ∈ R^(N\_int\*r × N\_int\*r):&nbsp;   	For each interior node x\_m:&nbsp;           For i in {x, y}:&nbsp;           	For j in {x, y}:&nbsp;                   Add stencil / FE contribution for term:&nbsp;                   ∂\_i ( A\_ij ∂\_j ℓ )&nbsp;           Implement r×r block coupling between latent channels###### ###### &nbsp;     4B: Solve elliptic PDE independently for each time slice###### &nbsp;	For each time slice t\_n:&nbsp;   	    Initialise RHS vector rhs^(n) = 0 ∈ R^(N\_int\*r)&nbsp;           For each interior node x\_m:&nbsp;               For each boundary neighbour x\_b in stencil of x\_m:&nbsp;           	   rhs^(n) += (stencil block coefficient) × f\_k^(n)(x\_b)&nbsp;   	Solve linear system:&nbsp;           K\_xy(A\_xy) · L^(n) = rhs^(n)&nbsp;   	Recover PDE-predicted latent field:&nbsp;           ℓ\_pde(x\_m, t\_n) from L^(n) for all interior nodes&nbsp;   	Interpolate (if required) to spatial patch centre:&nbsp;           ℓ\_pde(p\_xy, t\_n)&nbsp;	Return ℓ\_pde######       5) Latent consistency loss (encoder vs elliptic-predicted)         loss\_latent += || ℓ\_true - ℓ\_hat ||^2 ######       6) Decode predicted latent to reconstruct u locally         u\_hat\_patch = decode\_patch(NN\_dec, ℓ\_hat, D\_dec)        u\_true\_patch = extract(u\_i, neighbourhood = p\_k + D\_dec)      loss\_recon += mean\_over\_patch( || u\_true\_patch - u\_hat\_patch ||^2 )######    7) Regularisation to keep A SPD (barrier or factorisation)    loss\_spd = -ρ \* logdet(A)          if using barrier style (like paper)    OR if using factorisation A = L L^T + εI then loss\_spd = 0    batch\_loss = (loss\_latent / M) + α\*(loss\_recon / M) + loss\_spd    Take Adam step on parameters of:    NN\_e\_int, NN\_e\_bdy, NN\_dec, A\_raw    total\_loss += batch\_loss  Print epoch metrics (total\_loss, latent loss, recon loss)# \## AFTER TRAININGGiven new boundary observation b on ∂D:###### 1\) Encode latent boundary:   For each boundary point s ∈ ∂D:       ℓ\_bdy(s) = ε∂^(4D)(b)(s)###### 2\) Solve global 4D latent elliptic system on D:   ∇·(A ∇ℓ) = 0  in D   ℓ = ℓ\_bdy     on ∂D   -> obtain ℓ(s) for all interior s=(x,y,t)###### 3\) Decode latent to predict field:   u\_hat(s) = δ^(4D)(ℓ)(s)  # via NN\_dec applied semi-locallyReturn u\_hat(x,y,t)
