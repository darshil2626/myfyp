# \## DURING TRAINING#### Given:  training set { (u\_i on D, b\_i on ∂D) } for i=1..N  latent dim r  patch shapes:     E\_int ⊂ R^3       (interior patch in x,y,t)     E\_bdy ⊂ R^2       (boundary patch in boundary coordinates)     D\_dec ⊂ R^3       (decoder patch in x,y,t)  hyperparams α (reconstruction weight), ρ (SPD barrier), lr, epochs#### Initialize:  NN\_e\_int       interior encoder GF   ẽ\_int: R^(n\*NE\_int) -> R^r  NN\_e\_bdy       boundary encoder GF   ẽ\_bdy: R^(n\_bdy\*NE\_bdy + geom) -> R^r  NN\_dec         decoder GF            d̃: R^r -> R^(n\*ND\_dec)  A\_raw          unconstrained params for A (later mapped to SPD)#### Define SPD map:  A = SPD(A\_raw)   e.g. A = L L^T + εI, or symmetric + logdet barrier###### For epoch = 1..epochs:  total\_loss = 0######   For each minibatch B ⊂ {1..N}: (subset of data that is used for one gradient operation)    loss\_latent = 0    loss\_recon  = 0######     For each sample i in B: (subset of data in one minibatch)######      1) Sample M random 4D training patches Q\_k ⊂ D (in x,y,t). Each patch is a small 3D box around a centre p\_k      Choose centres p\_k ∈ D,  k=1..M      Define patches Q\_k = box(p\_k; hx, hy, ht)      For k = 1..M: (loop through each sample) ######       2) Build "true" latent at centre via interior encoder         u\_patch = extract(u\_i, neighbourhood = p\_k + E\_int)        ℓ\_true = NN\_e\_int( pool(u\_patch) )    pool = averages over E\_int subcells######       3) Build latent boundary data on ∂Qₖ (If I only knew the latent variables on the boundary of this small space–time patch, could an elliptic PDE reconstruct the latent variable at the centre?)        Inputs (for one training sample i and one patch Q\_k):        u\_i          : ground-truth interior field on D = Ω×\[0,T]   (training only)        b\_i          : observed boundary data on ∂D                 (train \& test)        Q\_k          : a 3D space–time patch (e.g. small box) with centre p\_k        {q\_j}        : discrete boundary grid points on ∂Q\_k, j=1..N\_b        E\_int        : interior encoder neighbourhood shape in R^3        E\_bdy        : boundary encoder neighbourhood shape in boundary coordinates        NN\_e\_int     : interior encoder network  (semi-local GF)        NN\_e\_bdy     : boundary encoder network  (semi-local GF)        pool\_int(.)  : pooling operator to turn local patch values into a vector        pool\_bdy(.)  : pooling operator for boundary neighbourhood        geom(.)      : function that returns local boundary geometry/orientation features        Output:        f\_k          : boundary condition function on ∂Q\_k (discrete or interpolated), representing ℓ|∂Q\_k######       3A) Evaluate discrete latent values on boundary points        Initialize array L\_bdy\[j] ∈ R^r for j = 1..N\_b        For each boundary point q\_j on ∂Q\_k:          Determine whether q\_j lies on the TRUE global boundary ∂D or not.          if is\_on\_global\_boundary(q\_j):            --- Use BOUNDARY encoder: ε∂(b) ---            1) Extract local neighbourhood of boundary observations around q\_j            b\_local = extract\_boundary\_neighbourhood(b\_i, centre=q\_j, shape=E\_bdy)            2) Extract geometry / orientation features at q\_j              Examples:                - spatial outward normal n(x,y) if (x,y)∈∂Ω                - a "time normal" ±e\_t if q\_j lies on t=0 or t=T surface                - tangential directions / side-id / signed distance to corners            g\_local = geom(q\_j)            3) Pool neighbourhood into finite vector (averages over bins etc.)            z\_bdy = pool\_bdy(b\_local, g\_local)            4) Encode to latent            L\_bdy\[j] = NN\_e\_bdy(z\_bdy)          else:            --- Use INTERIOR encoder: ε(u) ---            1) Extract local space–time neighbourhood of u around q\_j (training only)            u\_local = extract\_interior\_neighbourhood(u\_i, centre=q\_j, shape=E\_int)            2) Pool neighbourhood into finite vector            z\_int = pool\_int(u\_local)            3) Encode to latent            L\_bdy\[j] = NN\_e\_int(z\_int)######       3B) Convert discrete boundary latents into boundary condition f\_k - function/set of vectors containing the latent boundary points of the patch        Use L\_bdy\[j] directly as Dirichlet values at boundary nodes.        PDE solver will apply them at those nodes.        f\_k\_boundary\_nodes := { (q\_j, L\_bdy\[j]) } for j=1..N\_b######       4) Solve 4D latent elliptic PDE on the patch         Inputs:        Q\_k                  : patch domain (3D box in x,y,t)        f\_k (Dirichlet BC)   : latent boundary condition on ∂Q\_k from Step 3        A                    : SPD elliptic coefficient matrix in R^(3r × 3r)        grid(Q\_k)            : internal discretisation nodes of the patch        solve\_linear\_system  : SPD solver (Cholesky/CG/etc.)        Output:        ℓ\_hat\_k              : predicted latent at centre point p\_k (vector in R^r)######       4A) Discretise the latent elliptic operator on Q\_k        solve: ∇·(A ∇ℓ) = 0  in Q\_k,  ℓ = f\_k  on ∂Q\_k        ℓ is R^r-valued at each grid node.        Define interior grid nodes:   {x\_m} for m = 1..N\_int    (each x\_m ∈ Q\_k)        Define boundary grid nodes:   {x\_b} for b = 1..N\_bnd    (each x\_b ∈ ∂Q\_k)        Unknowns:            ℓ\_m ∈ R^r for each interior node x\_m        Known Dirichlet:            ℓ\_b = f\_k(x\_b) ∈ R^r for each boundary node x\_b        Build linear system K(A) \* L = rhs            where:              - L stacks all interior unknown latent vectors: L ∈ R^(N\_int \* r)              - K is (N\_int\*r)×(N\_int\*r) SPD              - rhs contains contributions from Dirichlet boundary nodes  	Treat A as a 3×3 block matrix with r×r blocks:            A = \[\[A\_xx, A\_xy, A\_xt],                 \[A\_yx, A\_yy, A\_yt],                 \[A\_tx, A\_ty, A\_tt]]        Then discretise each term with central differences on the 3D grid.        For each interior node x\_m:            For i in {x,y,t}:  		For j in {x,y,t}:     			add stencil for  ∂i( A\_ij ∂j ℓ ) ######       4B) Impose Dirichlet boundary conditions from f\_k        For each interior node equation affected by neighbouring boundary nodes:            Move known boundary contributions to rhs:                rhs += (stencil coefficient) \* f\_k(boundary\_node)######       4C) Solve for interior latent field on the patch        L\_solution = solve\_linear\_system(K, rhs)        # L\_solution ∈ R^(N\_int\*r)        Reconstruct ℓ\_hat\_field on grid nodes:            For each interior node x\_m:                ℓ\_hat\_field\[x\_m] = unpack\_r\_vector(L\_solution, m)        Optionally, also store boundary values for completeness:            ℓ\_hat\_field\[x\_b] = f\_k(x\_b)######       4D) Extract predicted latent at patch centre p\_k        If p\_k is a grid node:            ℓ\_hat\_k = ℓ\_hat\_field\[p\_k]        If p\_k is not exactly on the grid:            ℓ\_hat\_k = trilinear\_interpolate(ℓ\_hat\_field, location=p\_k)        Return ℓ\_hat\_k  (and optionally ℓ\_hat\_field)######       5) Latent consistency loss (encoder vs elliptic-predicted)         loss\_latent += || ℓ\_true - ℓ\_hat ||^2 ######       6) Decode predicted latent to reconstruct u locally         u\_hat\_patch = decode\_patch(NN\_dec, ℓ\_hat, D\_dec)        u\_true\_patch = extract(u\_i, neighbourhood = p\_k + D\_dec)      loss\_recon += mean\_over\_patch( || u\_true\_patch - u\_hat\_patch ||^2 )######    7) Regularisation to keep A SPD (barrier or factorisation)    loss\_spd = -ρ \* logdet(A)          if using barrier style (like paper)    OR if using factorisation A = L L^T + εI then loss\_spd = 0    batch\_loss = (loss\_latent / M) + α\*(loss\_recon / M) + loss\_spd    Take Adam step on parameters of:    NN\_e\_int, NN\_e\_bdy, NN\_dec, A\_raw    total\_loss += batch\_loss  Print epoch metrics (total\_loss, latent loss, recon loss)# \## AFTER TRAININGGiven new boundary observation b on ∂D:###### 1\) Encode latent boundary:   For each boundary point s ∈ ∂D:       ℓ\_bdy(s) = ε∂^(4D)(b)(s)###### 2\) Solve global 4D latent elliptic system on D:   ∇·(A ∇ℓ) = 0  in D   ℓ = ℓ\_bdy     on ∂D   -> obtain ℓ(s) for all interior s=(x,y,t)###### 3\) Decode latent to predict field:   u\_hat(s) = δ^(4D)(ℓ)(s)  # via NN\_dec applied semi-locallyReturn u\_hat(x,y,t)
